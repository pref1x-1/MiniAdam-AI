מדיניות פרטיות

מי מפעיל את הפרויקט

MINI ADAM הוא פרויקט עצמאי של Adam / Pref1x. האתר הוא אתר מידע והורדה סטטי שמפורסם באמצעות GitHub Pages. לפניות בנוגע לפרטיות ניתן לפתוח Issue במאגר GitHub; אין לפרסם שם מידע אישי או רגיש.

מידע שנאסף באתר

האתר אינו כולל חשבון משתמש, טופס יצירת קשר, מערכת תגובות או כלי אנליטיקה/פרסום שהוטמעו על ידי הפרויקט. האתר שומר בדפדפן, באמצעות localStorage, את בחירת השפה ואת העדפות כלי הנגישות בלבד. אפשר למחוק אותן דרך הגדרות הדפדפן.

כדי להציג את קובץ ההתקנה האחרון, הדפדפן מבקש את פרטי ה־Release הציבורי מ־GitHub API. הבקשה נשלחת ל־GitHub, שעשוי לעבד כתובת IP, פרטי דפדפן ונתוני בקשה לפי מדיניות הפרטיות שלו. קובץ ההתקנה עצמו יורד מ־GitHub Releases.

האתר מתארח ב־GitHub Pages. GitHub עשויה לעבד נתוני שרת ותפעול בהתאם למדיניות ולתנאים שלה. לפרטים ראו את מדיניות הפרטיות של GitHub.

בנוסף, האתר טוען את גופן Assistant ואת אייקוני Material Symbols Rounded דרך Google Fonts. בקשות אלה נשלחות לשרתי Google Fonts; Google עשויה לעבד כתובת IP, פרטי דפדפן ונתוני בקשה לצורך אספקת המשאבים ובהתאם למדיניות הפרטיות שלה.

מידע באפליקציית MINI ADAM

לפי אופן הפעולה המתוכנן של האפליקציה, היסטוריית שיחות, זיכרונות והעדפות משתמש נשמרים במחשב המקומי, תחת תיקיית הנתונים של המשתמש ב־Windows (למשל ‎%APPDATA%\\MiniAdam). האתר אינו מקבל את תוכן השיחות או את הזיכרונות האלה.

כאשר נבחר מודל מקומי של Ollama, בקשות ההסקה נשלחות לשירות Ollama המקומי במחשב. הורדת מודלים, עדכונים, קישורים חיצוניים ושימוש בשירות ענן או ספק חיצוני עשויים להעביר נתונים או בקשות לאותו ספק. יש לעיין במדיניות ובתנאי השירות של כל ספק שבחרת.

פעולות Agent עשויות לקרוא או לשנות קבצים בתוך אזור העבודה שהוגדר. יש לבדוק בקשות אישור, לשמור גיבויים ולא להזין מידע רגיש שאינך רוצה לעבד במערכת.

עוגיות, שמירה והסרה

בגרסה זו האתר משתמש ב־localStorage להעדפות שפה ונגישות ואינו מציב בכוונה עוגיות מעקב. שירותי GitHub או ספקים חיצוניים עשויים להשתמש בטכנולוגיות משלהם בעת מעבר אליהם.

העדפות האתר נשארות בדפדפן עד למחיקת נתוני האתר. נתוני אפליקציה מקומיים נשארים במחשב עד שתמחק אותם דרך האפליקציה או מערכת ההפעלה. לפני הסרה או איפוס, מומלץ לגבות קבצים חשובים.

אבטחה ושינויים במדיניות

נעשים מאמצים סבירים להגן על האתר ועל קובצי ההפצה, אך אין אפשרות להבטיח אבטחה מוחלטת. המתקין אינו חתום דיגיטלית, ועלולות להופיע אזהרות אבטחה. אין לעקוף זיהויים של Defender או SmartScreen.

מדיניות זו עשויה להתעדכן כאשר האתר או האפליקציה משתנים. הגרסה העדכנית תפורסם בעמוד הזה ותישא תאריך עדכון.
