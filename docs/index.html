01 / CONVERSATION

שיחות שמרגישות מסודרות

נהל היסטוריה, חפש שיחות, ערוך הודעות, שכפל ענפים, הוסף סימניות וייצא תוכן — בלי להפוך את המסך לעמוס.

אישיות וזיכרון

שליטה במודלים

גלה מודלים, הורד, בחר, רענן, פרוק או מחק אותם מתוך הממשק.

04 / CONTEXT

צרף קבצים ותמונות לשיחה. הבנת תמונות דורשת מודל Vision תואם.

לא מצאת תשובה? אפשר לפתוח Issue במאגר GitHub.

האם MINI ADAM מתקין את Ollama?

לא. Ollama מותקן בנפרד מהאתר הרשמי. לאחר מכן MINI ADAM יכול לזהות את השירות המקומי ולהתחבר אליו.

האם השיחות נשלחות לענן?

בשימוש במודל Ollama מקומי, ההסקה מתבצעת במחשב והנתונים נשמרים מקומית. שימוש בספק ענן או בשירות חיצוני, אם תבחר בו, עשוי להעביר אליו מידע.

האם Adam Mode חייב להיות פעיל?

לא. Adam Mode הוא אפשרות. אפשר להפעיל או לכבות אותו לכל שיחה בנפרד ולבחור ברירת מחדל בהגדרות.

האם מודלים כלולים במתקין?

לא. המתקין כולל את MINI ADAM. את Ollama ואת המודלים מורידים בנפרד. גודל המודל משפיע על נפח האחסון, הזיכרון והמהירות.

למה Windows עשוי להציג אזהרת אבטחה?

המתקין אינו חתום דיגיטלית. אין לעקוף זיהוי של Defender או SmartScreen ואין להוסיף חריגות. הורד רק מהמקור הרשמי ואמת את SHA-256.
