לפני שמתחילים.

האם MINI ADAM מתקין את Ollama?

לא. מתקינים את Ollama בנפרד מהאתר הרשמי.

האם השיחות נשלחות לענן?

בשימוש במודל Ollama מקומי, העיבוד מתבצע במחשב שלך והנתונים נשמרים מקומית. הורדות ועדכונים דורשים אינטרנט.

האם Adam Mode חייב להיות מופעל?

לא. אפשר להפעיל או לכבות בכל שיחה ולבחור ברירת מחדל בהגדרות.

למה Windows עשוי להציג אזהרת אבטחה?

המתקין אינו חתום דיגיטלית. אין לעקוף זיהוי של Defender או להוסיף חריגות. הורד רק מהמקור הרשמי ואמת SHA-256.

האם המודלים כלולים במתקין?

לא. המתקין כולל את MINI ADAM בלבד. מורידים מודלים בנפרד לפי החומרה והשטח הפנוי.

מוכן ל־AI מקומי?

התחל מהמתקין הרשמי, התקן Ollama ובחר מודל שמתאים למחשב.
