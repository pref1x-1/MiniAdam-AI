לפני שמתחילים.

תשובות קצרות לשאלות הנפוצות על MINI ADAM.

האם MINI ADAM מתקין את Ollama?

לא. Ollama מותקן בנפרד מהאתר הרשמי. לאחר מכן MINI ADAM יכול להתחבר לשירות המקומי.

האם השיחות נשלחות לענן?

בשימוש במודל Ollama מקומי, ההסקה מתבצעת במחשב והמידע נשמר מקומית. שימוש בשירות ענן חיצוני עשוי להעביר מידע לספק השירות.

האם Adam Mode חייב להיות פעיל?

לא. Adam Mode הוא אפשרות. אפשר להפעיל או לכבות אותו בכל שיחה בנפרד ולבחור ברירת מחדל בהגדרות.

האם המודלים כלולים במתקין?

לא. המתקין כולל את MINI ADAM בלבד. את Ollama והמודלים מורידים בנפרד.

למה Windows עשוי להציג אזהרת אבטחה?

המתקין אינו חתום דיגיטלית. אין לעקוף זיהוי של Defender או SmartScreen. הורד רק מהמקור הרשמי ואמת את SHA-256.
