תוצרי בינה מלאכותית

תשובות שמודלים מייצרים עלולות להיות שגויות, חלקיות, מוטות, לא מעודכנות או מומצאות. MINI ADAM אינו מבטיח נכונות, מקוריות או התאמה של תשובה למטרה שלך.

אין לראות בתשובות תחליף לייעוץ רפואי, משפטי, פיננסי, בטיחותי או מקצועי אחר. בדוק מידע חשוב מול מקורות מוסמכים ואיש מקצוע מתאים.

מודלים ורישיונות

MINI ADAM הוא ממשק ושכבת התאמה אישית, לא מודל בסיס חדש שעבר בהכרח אימון נוסף. יכולות כמו ניתוח תמונות, הצגת חשיבה, ביצועים ואיכות שפה תלויות במודל שהתקנת, בגרסה שלו, בחומרה וברכיבי Ollama. מודלים שהורדו מ־Ollama או Hugging Face כפופים לרישיונות שלהם.

פרטיות ועיבוד מקומי

כאשר נעשה שימוש במודל Ollama מקומי, בקשות ההסקה מטופלות על ידי שירות מקומי במחשב. עם זאת, הורדת מודלים, בדיקת גרסאות, עדכונים, קישורים חיצוניים או בחירה בספק ענן עשויים ליצור תקשורת עם שרתים חיצוניים. אין להניח שכל פעולה באפליקציה היא Offline.

פעולות Agent וקבצים

פעולות Agent עשויות לקרוא, ליצור, לשנות או למחוק קבצים באזור העבודה המאושר. גם כאשר מוצגת בקשת אישור, המשתמש אחראי לבדוק את הפעולה והיעד שלה לפני האישור ולשמור גיבויים. אין להשתמש בפעולות Agent עם קבצים שאין לך הרשאה לשנות.

אבטחה ותאימות

קובצי ההפצה אינם חתומים דיגיטלית, ותאימותם לא נבדקה בכל שילוב של חומרה, גרסת Windows ומנוע אבטחה. ייתכן שיופיעו אזהרות של Windows או אנטי־וירוס. אין לכבות הגנות אבטחה או להוסיף חריגות כדי להפעיל את התוכנה. במקרה של זיהוי, עצור, אמת את מקור הקובץ ופנה לבדיקה.

סימני מסחר והיעדר חסות
