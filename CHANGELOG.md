# MINI ADAM — Changelog

## 3.6.0 · Glass Edition
**30 October 2026**

### Desktop

- Introduced the Graphite and Emerald Glass visual system.
- Standardized typography with Assistant and icons with Material Symbols Rounded.
- Refined navigation, spacing, dialogs, menus, notifications, and responsive layouts.
- Improved readable text sizes, focus states, and reduced-motion support.

### Conversations

- Expanded conversation management with rename, duplicate, pin, favorites, folders, tags, bookmarks, statistics, and restore points.
- Added Markdown, HTML, and JSON export.
- Improved clear and delete flows.

### Local AI

- Retained local Ollama inference as the default.
- Kept chat history and memories on the local device.
- Kept confirmation steps for Agent file operations.

### Website

- Added a live GitHub star count and a compact FAQ.
- Added floating navigation and a glass-style footer.
- Added Contact, Changelog, and custom 404 pages.
- Added release-aware SHA-256 verification.
- Set English as the default language with a Hebrew (HE) switch.
